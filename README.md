# CodeLobbyStudio

**CodeLobby** is a collaborative live-coding platform designed for university laboratories and programming workshops.

Any account can create a lobby and become its **Host**. Other users join using a code or link as **Participants**. The Host provides task instructions, starter code and tests separately for each supported language offered in a task. Participants complete the code in the browser and receive evaluation feedback.

## Repositories

- [codelobby-backend](https://github.com/CodeLobbyStudio/codelobby-backend) — API, authentication, lobbies, tasks and submissions
- [codelobby-web](https://github.com/CodeLobbyStudio/codelobby-web) — web UI and code editor
- [codelobby-runner](https://github.com/CodeLobbyStudio/codelobby-runner) — isolated execution and assessment of submitted code

## Collaboration

Work is organized in the **CodeLobby Development** GitHub Project. Each Issue describes a focused task and changes are reviewed via Pull Requests.
